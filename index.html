What Is the Fate Series?

Fate is a franchise by Type-Moon built around the Holy Grail Wars, where summoned heroic spirits called Servants fight for a wish-granting Grail. The story is told across many separate timelines, so the order you watch it in matters.

Chronological Order

Fate has no single timeline, so this order groups the stories by timeline. The first group is the core story. The others can be watched in any order after it.

Filler and Skip Guide

Fate has almost no traditional filler. These are the entries you can skip without losing the main story.

  • Skip: Fate/stay night (2006) if you plan to watch Unlimited Blade Works.
  • Skip: Fate/Grand Carnival, which is comedy shorts.
  • Optional: Prisma Illya, Apocrypha, Extra Last Encore and Lord El-Melloi II's Case Files.
  • Essential: Fate/Zero, Unlimited Blade Works and the Heaven's Feel movies.

Quick Tip

New to Fate? Start with Fate/Zero, then Unlimited Blade Works, then the Heaven's Feel movies.
